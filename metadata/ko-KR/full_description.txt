시프트 키 없이 한글 두벌식(두벌식 순아래)을 입력하는 가볍고 빠른 키보드입니다.

키보드 사용 방법:

* 런처에서 "순아래 키보드"를 실행합니다
* 순아래 키보드를 활성화합니다 (기본 시스템 경고가 표시됩니다)
* 현재 입력기에서 순아래 키보드로 전환합니다 (키보드마다 다르지만, 보통 스페이스바를 길게 누르면 됩니다)
* 순아래 키보드 설정은 ","를 길게 누르거나 시스템 설정 → 언어 및 입력 → 순아래 키보드에서 변경합니다

<b>특징:</b>

* 작은 크기 (&lt;1MB)
* 화면을 더 많이 쓰기 위한 키보드 높이 조절
* 숫자 줄
* 스페이스 스와이프로 커서 이동
* 스와이프로 삭제
* 사용자 지정 테마 색상
* 최소 권한 (진동만 사용)
* 광고 없음

<b>제공하지 않는 기능:</b>

* 이모지
* GIF
* 맞춤법 검사기
* 스와이프 입력
